# GitHub Pages Docs

This folder is ready to be published as a static website for HandwritingAnalysis.

## Pages included
- `index.html` (public docs landing page)
- `privacy-policy.html`
- `terms-of-use.html`
- `disclaimer.html`
- `support.html`
- `scientific-references.html`
- `play-store-checklist.md` (internal publication checklist)

## Publish from GitHub
1. Push this repository to GitHub.
2. Open repository `Settings` -> `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select branch (`main` or `master`) and folder `/docs`.
5. Save and wait for deployment.
6. Copy resulting URL, for example:
   - `https://<github-username>.github.io/<repo-name>/privacy-policy.html`

## Google Play fields
Use public URLs from this folder for:
- Privacy Policy URL (required)
- Developer website/support links (optional but recommended)

Keep support contact details in Google Play listing aligned with these pages.
